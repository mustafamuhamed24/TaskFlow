## Overview

TaskFlow is a responsive project management application designed to help individuals and teams organize work, monitor progress, and manage tasks through an intuitive dashboard.

The project demonstrates modern React development, reusable components, client-side routing, state management, and responsive UI design.

## Features

- 📊 Dashboard with project and task statistics
- 📋 Kanban board with task status columns
- ✅ Create, edit, and delete tasks
- 🔍 Search and filter tasks
- 🏷️ Priority, due dates, and task status
- 🔄 Drag-and-drop task organization, if implemented
- 💾 Persistent demo data using localStorage
- 📱 Responsive layout for desktop, tablet, and mobile
- ⚠️ Form validation and useful error states

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- React Router
- Lucide icons
- localStorage

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

```bash
git clone YOUR_REPOSITORY_URL
cd TaskFlow
npm install
npm run dev
```

Open the local URL shown in your terminal.

### Available Scripts

```bash
npm run dev
npm run build
npm run preview
```

Run `npm run lint` if the project includes a lint script.
